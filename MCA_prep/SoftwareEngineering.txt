Phases of SLDC.
Requirement analysis
Require analysis. First phase of SLDC which state the problem precisely, 
it forms the basis of agreement between user and developer. 
It specifies "what" not "how". 
and output is the SRS (Software Requirement Specification) document. 

Design.
Design is the major step in moving from problem domain to solution domain. This includes Architectural design High level design and detail design. 

Architectural design is the process of defining the components and the connectors in the system. 
High level design is the process of designing the modules and data structures in the architecture
Detail design is the process of designing the logic of the modules. 

Coding.
In this phase, the developers write code according to the design specification using a programming language. 
Coding converts the design into code in specific language. 
Coding phase effects both testing and maintenance. 

Testing
In testing phase, the testers tests The functionality of the system or program.
Defects gets found in the stage Defects like bugs and errors must be found and removed to achieve high quality as the user expected.

Development. 
After all these phases, the program or software is deployed to the production environment. 
Deployment involves installation, configuration and making it available to end users.

Maintenance.
The phase involves maintaining monitoring, bug fixing, troubleshooting and making updates as needed. 
It aims to ensure enhancement of the user experience.

Waterfall model is the oldest and widely used model

Feasibility study. 
Feasibility study is a study to whether a project is feasible or not.
It evaluates whether the is cost effective or not? 
It evaluates whether the project can be implemented using the available technologies and resources.
